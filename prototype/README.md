# Prototype

Le premier prototype, en un seul fichier HTML. Il est **gardé comme référence** pendant que la vraie app est construite dans [`app/`](../app/). Il ne sera plus développé.

| Fichier | Rôle |
|---|---|
| `index.html` | Le prototype |
| `donnees.js` | Les cartes, généré par `npm run construire` à partir de `data/`. Ne pas modifier à la main. |

Pour l'essayer, ouvre `index.html` dans un navigateur. Codes de stand de démonstration : `COMMUNE-71`, `MUR-28-MAI`, `18-MARS-2027`.
